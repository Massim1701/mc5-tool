⏰ Beste Posting-Zeiten (pro Wochentag)

Aus X's "Aktive Zeiten"-Heatmap abgelesen (deine lokale Zeitzone). Für Tage ohne eigene Zeit gilt der Standard-Wert. Mehrere Zeiten pro Tag mit Komma trennen.

Die Ø-Werte unter jedem Tag stammen aus deinen importierten CSV-Daten (Reichweite pro Wochentag) – die Uhrzeit selbst musst du weiterhin manuell eintragen, da X das nicht exportiert.

🤖 Gemini API-Key (kostenlos)

Wird nur lokal in deinem Browser gespeichert (localStorage), niemals irgendwo hochgeladen. Nötig für den Tweet-Generator ("Did You Know?" / "Story behind..."). Kostenlos zu bekommen unter aistudio.google.com/apikey (kein Kreditkarte nötig, mit Google-Konto einloggen, "Create API Key" klicken).

💾 Backup / Datensicherung

Alle deine Daten (Planner, Archiv, CSV-Historie, Einstellungen) liegen nur in diesem Browser. Sichere sie regelmäßig als Datei – so gehen sie bei Browser-Wechsel oder Cache-Löschung nicht verloren.

☁️ Google Drive Sync

Verbinde dein Google Drive, damit dein Mission-Control-Stand direkt dort landet - ohne Datei-Download/Upload per Hand. Die Verbindung sieht ausschließlich Dateien, die Mission Control selbst anlegt (Ordner "Mission Control Sync"), nicht dein restliches Drive.
